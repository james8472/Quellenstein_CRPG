# Das wichtigste System

Nicht Kampf.

Nicht Inventar.

Nicht Quests.

Sondern:

DiceManager

---

Beispiel:

enum DiceTier  

{  

D4,  

D6,  

D8,  

D10,  

D12  

}

func roll_pair(tier:int):  

var sides = get_sides(tier)  

var d1 = randi_range(1,sides)  

var d2 = randi_range(1,sides)  

return {  

"die1": d1,  

"die2": d2,  

"sum": d1 + d2,  

"pasch": d1 == d2  

}

# Der eigentliche Kern für Quellenstein

GameManager  

└─ CombatManager  

└─ DiceManager  

└─ PaschResolver

Denn jede Aktion:

- Angriff
- Dialog
- Magie
- Handwerk
- Überreden
- Wahrnehmung

läuft über:

2 Würfel  

↓  

Pasch prüfen  

↓  

Sonderereignis auslösen

entsprechend dem QPnP-System. [[quellenstein.de]](https://www.quellenstein.de/), [[Quellenste...akterbögen | PDF]](https://onedrive.live.com/?cid=406DA00EB225498E&id=406DA00EB225498E!s508b1b0efaf74d07bc3da109a4d41b9b)
