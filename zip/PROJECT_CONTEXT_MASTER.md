# Projektvision

Quellenstein RPG ist ein isometrisches 2D-CRPG auf Basis von Godot 4.  

Das Projekt nutzt die Welt Eltherana und die Lore von Quellenstein, erzählt jedoch eine eigenständige Geschichte.  

Wichtig:  

- Keine Romanadaption  

- Keine Quellenstein-Hauptstory  

- Keine Prophezeiung als Hauptquest  

- Keine Weltenrettung  

Der Roman dient ausschließlich als Lore- und Hintergrundquelle.  

Das Spiel konzentriert sich auf:  

- Exploration  

- Gruppenspiel  

- Taktische Kämpfe  

- Dungeons  

- Geheimnisse  

- Ruinenforschung  

---

# Scope Freeze

Diese Entscheidungen gelten als fest:  

✅ Maximal 5 Gruppenmitglieder  

✅ Feste Gruppe von Beginn an  

✅ Keine Rekrutierung  

✅ Keine Companions  

✅ Echtzeit mit Pause  

✅ Quellenstein-Regeln als Grundlage  

✅ Maximalstufe 10  

✅ Lokale Geschichte  

✅ Alter Wald als Hauptgebiet  

✅ Tempel von Khar-Nareth als Hauptdungeon  

✅ Arzakar als Endgegner

# Hauptgeschichte

## Ausgangssituation

Nahe Immenfurt verschwinden:  

- Holzfäller  

- Jäger  

- Tiere  

Gleichzeitig treten seltsame Ereignisse im Alten Wald auf.  

Der Rat von Immenfurt entsendet eine Untersuchungsgruppe.  

Die fünf Helden übernehmen diese Aufgabe.  

---  

# Die Bedrohung

Eine vergessene Tempelruine wird entdeckt.  

Unter dieser Ruine befindet sich:  

- ein uralter Tempel  

- eine Reihe versiegelter Kammern  

- ein Gefängnis  

Darin befindet sich:  

## Arzakar

Ein uraltes dämonisches Wesen.  

Arzakar ist:  

- kein Gott  

- kein Weltenzerstörer  

- keine Prophezeiungsfigur  

Arzakar kann:  

- Menschen korrumpieren  

- Träume beeinflussen  

- Tiere verändern  

- Kultisten anziehen
